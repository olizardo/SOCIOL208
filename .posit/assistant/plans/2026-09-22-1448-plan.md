## RESOLVED: New Data Analysis Exercises (Weeks 7, 9, and 10) + Renumbering — Full 10-Week Symmetry

Per user instruction, three new exercises are added — for Weeks 7, 9, and 10 — giving every one of the 10 weeks its own Data Analysis Exercise (full I–X symmetry). All follow the existing exercise template (pick network data → reproduce lecture-note analyses → produce a table/model output → one paragraph of interpretation → submit as R Markdown + rendered HTML/PDF).

- **New: "Data Analysis Exercise VII: Advanced Community Detection"** (Week 7) — draft description: *"Pick some network data (from a repository or the `networkdata` package) and reproduce some of the analyses in the lecture notes on advanced/overlapping community detection, using at least one clique-percolation, correspondence-analysis, or two-mode spectral clustering method. Compare the overlapping or spectral partition you obtain to the standard (non-overlapping) partition from the prior week's methods on the same network. Write one short paragraph on what the additional structure reveals that the simpler partition did not. Submit your work as an R Markdown file and its rendered HTML/PDF output."*
- **New: "Data Analysis Exercise IX: QAP and Permutation-Based Null Models"** (Week 9) — draft description: *"Pick some network data (from a repository or the `networkdata` package) along with at least one dyadic covariate or second network measured on the same nodes. Reproduce some of the analyses in the lecture notes on graph randomization and QAP, including (a) a degree-preserving random-graph/permutation null model comparison for at least one network statistic of your choosing, and (b) a QAP regression relating your network to the covariate or second network. Report your QAP coefficient table with permutation-based p-values. Write one short paragraph interpreting what the permutation test tells you that a standard (non-network) regression would not. Submit your work as an R Markdown file and its rendered HTML/PDF output."*
- **New: "Data Analysis Exercise X: Exponential Random Graph Models"** (Week 10) — draft description: *"Pick some network data (from a repository or the `networkdata` package) and fit at least one Exponential Random Graph Model (ERGM) using the `ergm` package, following the specification/estimation steps in the lecture notes. Report your model's coefficient table with standard errors and assess goodness-of-fit (e.g., via `gof()`). Write one short paragraph interpreting at least two parameter estimates in substantive terms. Submit your work as an R Markdown file and its rendered HTML/PDF output."*
